This application is a project developed as part of the Yandex Practicum curriculum. It is a classic implementation of the Snake game built with Python and the Pygame library.

## Game Overview

The player controls a snake that grows in length as it consumes food. The game ends if the snake hits the boundaries of the screen or its own body.

## Features

- Dynamic Movement: Smooth control using arrow keys.
- Score Tracking: Real-time score display.
- Restart Mechanic: Quick replay option after a Game Over.
- Collision Detection: Accurate boundary and self-collision logic.


## Getting Started

### Prerequisites

Make sure you have Python installed. You will also need the pygame library.

### Installation

#### 1. Clone the repository

   ```bash
   git clone https://github.com
   cd snake-python
   ```

#### 2. Install dependencies

   ```bash
   pip install pygame
   ```

#### 3. Run the game

   ```bash
   python main.py
   ```

## Controls

- Arrow Keys: Move the snake (Up, Down, Left, Right).
- C: Restart the game after losing.
- Q: Quit the game.
